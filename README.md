# MFDS Coach

A single-page revision guide for the MFDS (Membership of the Faculty of Dental Surgery) of the Royal College of Surgeons of England, written for the legacy format: Part 1 (150 single best answer questions) and Part 2 (14 stations).

Open `index.html` in a browser, or use the GitHub Pages site for this repository. It needs no install and no account.

## What's inside
- 70 lessons following the official RCS England syllabus, each with how it shows up in a question, the exam trap, and links to its primary sources
- 100 single best answer questions, 14 worked examples, 50 flashcards and 3 sorting games
- 12 Part 2 practice stations with a timer and mark sheet
- Interactive tools: BPE chart, periodontitis stage and grade calculator, local anaesthetic dose calculator, statistics lab, eruption chart and emergency simulator
- Click-through decision flowcharts, a syllabus map and a study plan

## Accuracy
Claims were compared with primary sources (NICE, SDCEP, BSP, IADT, the GDC, the BNF and others) in October 2026. See [VERIFICATION-REPORT.md](VERIFICATION-REPORT.md) for every correction and every item that could not be confirmed. Items marked "Unconfirmed: check" in the guide must be checked in the named guideline before you rely on them.

## Limits
- This is a study aid. It is not official RCS England material and is not affiliated with any college.
- It is written for the RCS England legacy MFDS. A new joint format starts from late 2026, so check your sitting and format on the college pages.
- Always use the current BNF and the current guidelines for doses and clinical decisions.
